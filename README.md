# Dubai Property Sentiment Tracker

Independent English keyword sentiment baseline. It shows two Dubai Land Department headlines and two clearly marked synthetic comments, or analyzes a CSV you upload with `date,source,text,url` columns. Node 20+: `npm start`, open `http://127.0.0.1:4206`, and run `npm test`.

This sample is not representative of Dubai market sentiment. The classifier does not understand sarcasm, Arabic or Russian. It does not scrape news or social networks. Use licensed data with clear provenance before making public claims.

## Live demo

[Open the interactive demo](https://aytajkhudiyeva.github.io/dubai-property-sentiment-tracker/). The GitHub Pages version runs in the browser. Use fictional data. The Node server remains available for local development and integration work.
